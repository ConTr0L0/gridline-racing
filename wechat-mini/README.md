# F1小助手 微信小程序

这是独立的微信小程序目标。Expo Android/Web App 仍使用仓库根目录；此子项目使用 Taro 4.3.0 和 React 18，不修改根目录依赖。

## 本地预览

1. 在此目录安装依赖：`npm install`
2. 编译微信小程序：`npm run build:weapp`
3. 打开微信开发者工具，导入 `dist/`；生成目录里的 `project.config.json` 已指向当前目录。
4. 核对已配置的小程序 AppID 与微信后台项目一致；不要将 AppSecret 或 API 密钥写进小程序。

监听模式：`npm run dev:weapp`。

## 已移植功能

- 首页和 2026 赛历；可用时从 OpenF1 同步赛程、场次及积分榜。
- 首页按最近场次显示倒计时，覆盖练习、冲刺排位、冲刺、排位及正赛；场次处于赛程时间窗口内时显示「正在进行」，隐藏倒计时。接口受限或旧缓存缺少时间时，使用 2026-10-09 核对的 F1 官方剩余七站时间表（`src/services/weekendSchedule.js`）。本地窗口不能反映延迟、红旗或提前结束，正赛预计结束时间不代表实际完赛。
- 车手、车队、赛道资料，以及本机收藏。
- 资料库、积分榜及收藏项可打开详情；车手与车队支持互跳、逐级返回。详情沿用 APP 的海报、赛车、统计卡片和赛道资料结构。
- 车手历站成绩和车队赛季统计按已同步场次显示覆盖数量；成绩保存在本机，缺失数据标为「—」。车队本地快照及生涯资料标注原资料日期。
- OpenF1 网络失败时优先显示本机缓存；首次离线时显示项目内赛历和资料快照。
- F1 官网实时计时入口复制官方链接。微信小程序内嵌普通网页需要在小程序管理后台配置业务域名，当前版本不假定外部域名已经获准。

微信后台还需要按平台要求配置 `https://api.openf1.org` 为合法 request 域名后，线上环境才可通过 `Taro.request` 同步数据。离线赛历/积分快照来自现有 F1 Gridline 项目，资料快照日期为 2026-09-13。

连接失败时，首页/赛程显示简短原因与数据来源，接口名称和具体错误保留在开发者工具控制台。2026-10-09 实测 OpenF1 返回 HTTP 401：F1 场次进行期间，所有未认证请求（包括历史数据）暂时受限。此时继续显示缓存或本地快照，场次结束后点按同步重试；关闭开发者工具域名校验不能解除服务端限制。若提示「请先配置请求域名」，应检查微信后台 request 合法域名；若提示超时，应检查运行设备的网络。不要把付费 API 凭据放入小程序源码或包内。

Android 主屏小组件、Expo OTA 更新、原生 Live Activity 和设置页属于原 Expo 宿主能力，本小程序没有复刻这些原生专属功能。

详情逻辑自检：`npm run check:details`。该检查使用模拟平台 API，不能替代微信开发者工具和真机验收。真机应核验三个详情入口、车手/车队互跳与返回、收藏星标不触发跳转、夜间主题和远程图片域名。

发布前先运行 `npm run build:weapp`，再运行 `npm run check:release`。上传参数、后台待核验项及真机验收见 `RELEASE_READY.md`。
